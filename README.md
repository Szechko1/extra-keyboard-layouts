# Magyar Billentyűzet / Hungarian Keyboard Layout

Magyar Glide billentyűzetkiosztás Android-hoz fizikai billentyűzetek számára.

Hungarian Glide keyboard layout for Android physical keyboards connected via OTG or Bluetooth.

## Mi az a Glide kiosztás? / What is Glide Layout?

A Glide egy ergonomikus magyar billentyűzetkiosztás, amely optimalizálja a gyakran használt karakterek elhelyezését. Főbb jellemzői:
- Y és Z billentyűk felcserélése (magyar nyelvű szövegekhez optimalizált)
- Számsor felső részén módosított elrendezés
- AltGr kombinációkkal könnyen elérhető speciális karakterek (€, ö, stb.)

Glide is an ergonomic Hungarian keyboard layout that optimizes the placement of frequently used characters. Main features:
- Y and Z keys swapped (optimized for Hungarian text)
- Modified arrangement on the number row
- Easy access to special characters with AltGr combinations (€, ö, etc.)

## Telepítés / Installation

Az alkalmazást telepítheted a [Releases](../../releases) oldalról, vagy közvetlenül a Google Play áruházból.

You can install the app from the [Releases](../../releases) page or directly from Google Play.

## Használat / Usage

1. Telepítsd az alkalmazást / Install the app
2. Csatlakoztass fizikai billentyűzetet USB vagy Bluetooth-on keresztül / Connect a physical keyboard via USB or Bluetooth
3. Menj a Beállítások > Rendszer > Nyelvek és bevitel > Fizikai billentyűzet menüpontba / Go to Settings > System > Languages & input > Physical keyboard
4. Válaszd ki a billentyűzetedet és állítsd be a "Hungarian Glide Layout" kiosztást / Select your keyboard and set the layout to "Hungarian Glide Layout"
